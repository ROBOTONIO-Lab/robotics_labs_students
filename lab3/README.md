# Lab 3 — Κιτ Ασφαλείας για ηλικιωμένους

**Η αποστολή:** Η γιαγιά μένει μόνη. Θα φτιάξεις μια συσκευή κομοδίνου που:
1. Ανάβει μόνη της ένα απαλό **φως νυκτός** όταν νυχτώνει.
2. Με ένα πάτημα στέλνει **SOS** — και με άλλο ένα το ακυρώνει.
3. Της **θυμίζει το φάρμακο** την ώρα που πρέπει.

Και όλα αυτά με **ΕΝΑ μόνο κουμπί**. Θα τα καταφέρει;

## Πίνακας συνδέσεων

| Εξάρτημα | Pin |
|---|---|
| Κίτρινο LED (φως νυκτός) | GP0 |
| Κόκκινο LED (SOS και φάρμακο) | GP1 |
| Buzzer | GP13 |
| Κουμπί | GP14 |
| Ποτενσιόμετρο | GP26 |
| Αισθητήρας φωτός (καλώδιο **DO**) | GP27 |

## Η κατασκευή σου πρέπει να περνά 4 τεστ

1. **Σταθερότητας** — πατάς το κουμπί δυνατά με ένα χέρι και η συσκευή δεν γλιστράει ούτε ανατρέπεται.
2. **Τυφλού χεριού** — με κλειστά μάτια βρίσκεις το κουμπί σε λιγότερο από 3 δευτερόλεπτα, χωρίς να ακουμπήσεις άλλο εξάρτημα.
3. **Ορατότητας** — και τα ΔΥΟ LED φαίνονται από 2 μέτρα, ακόμα και από χαμηλά («ξαπλωμένος στο κρεβάτι»).
4. **Αισθητήρα** — με το φως νυκτός αναμμένο, σκεπάζεις τον αισθητήρα και η συμπεριφορά αλλάζει καθαρά, χωρίς τρεμόπαιγμα. (Γιατί άραγε να τρεμοπαίζει;)
