# Φωτογραφίες για έμπνευση

Εδώ θα βρεις φωτογραφίες από κατασκευές του Κιτ Ασφαλείας — για ιδέες, ΟΧΙ για αντιγραφή.

Δεν υπάρχει «σωστή» κατασκευή. Η δική σου μπορεί να είναι εντελώς διαφορετική
από αυτές που βλέπεις — αρκεί να περνά τα 4 τεστ:
σταθερότητα, τυφλό χέρι, ορατότητα, αισθητήρας.

Καθώς κοιτάς τις φωτογραφίες, κάνε στον εαυτό σου τις ερωτήσεις του σχεδιαστή:

- Πού έβαλαν το κουμπί — και γιατί εκεί;
- Γιατί το κόκκινο LED κάθεται ψηλότερα από το κίτρινο;
- Προς τα πού κοιτάζει ο αισθητήρας φωτός; Τι θα γινόταν αν κοίταζε αλλού;
- Πού κρύβονται τα καλώδια;

Αν η δική σου κατασκευή περάσει και τα 4 τεστ με τρόπο που δεν έχουμε ξαναδεί,
φωτογράφισέ την — ίσως μπει κι αυτή εδώ, για τις επόμενες ομάδες!
