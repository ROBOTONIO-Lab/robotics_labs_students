## Οι κανόνες μας

- Δουλεύουμε σε ζευγάρια: **Προγραμματιστής** και **Μηχανικός** — αλλάζουμε ρόλους στη μέση.
- Ρεύμα στο κύκλωμα ΜΟΝΟ όταν το πει ο εκπαιδευτικός.
- Η μπαταρία 9V μπαίνει ΜΟΝΟ στη μαύρη υποδοχή DC — πουθενά αλλού.
- Όταν κάτι δεν δουλεύει: πρώτα κοιτάμε τα καλώδια, μετά τον κώδικα, μετά ρωτάμε.
